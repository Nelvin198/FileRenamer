# FileRenamer

A simple file renaming utility with **two implementations**:

- **Python CLI tool** – full‑featured, smart renaming logic  
- **Windows CMD tool** – minimal, office‑safe for restricted office environments

This project is designed for **real‑world use**, especially in environments where scripting permissions vary.

---

## Features

### Python Version
- Recursive folder support
- Partial filename matching
- Keeps existing numeric identifiers when present
- Sequential ID generation when missing
- Safe preview (dry‑run) mode
- Prevents overwriting files
- Cross‑platform (Windows, macOS, Linux)

### CMD Version
- Works in **strict office environments**
- No Python, PowerShell, or admin rights required
- Partial filename matching
- Sequential numbering
- Preserves file extensions
- Simple and predictable behavior
